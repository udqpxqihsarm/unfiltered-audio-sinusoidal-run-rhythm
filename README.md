## Overview

Unfiltered Audio Sinusoidal Run Rhythm is a rhythmic gate sequencer that applies sinusoidal amplitude modulation in sync with your tempo to create tremolo, gating, and pulsing effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unfiltered Audio Sinusoidal Run Rhythm** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Rhythm Gate** | 16-step gate sequencer with adjustable rate and depth per step |
| **Sinusoidal Mod** | Smooth sine wave amplitude shaping between gate states |
| **Tempo Sync** | Locks to DAW BPM with selectable note divisions |
| **Stereo Mode** | Independent left/right gate patterns for rhythmic stereo effects |
